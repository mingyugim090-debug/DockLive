# PAGE_SPECS — 수용 기준 (완료의 정의)

각 항목이 전부 체크돼야 그 페이지 태스크는 완료다.

## 랜딩 (/)
- [ ] 본문 전체에서 브랜드 표기 "DockLive"로 통일 (현재 "LiveDock" 오표기 존재)
- [ ] 지표를 사용자 언어로: "5종 fixture/6단계 Agent 흐름" → "무결성 통과율 N% ·
      공고→제출본 평균 N분 · HWPX 원본 구조 보존" (실측치 연동, 없으면 지표 노출 보류)
- [ ] CTA 도착지 = /app/new의 공고 붙여넣기 입력 (로그인 후에도 7섹션 대시보드 금지)
- [ ] 히어로 데모: 정적 목업 대신 6단계 스테퍼가 실제로 넘어가는 미니 데모 (fixture 재사용)
- [ ] "양식만 채우기" 보조 경로 링크 1개 (기존 HWPX 양식 작성 사용자 유입 보존)

## 사이드바 (전역)
- [ ] 항목 = 새 프로젝트 버튼 + 프로젝트 목록 + 계정. 그 외 0개
- [ ] 프로젝트 항목에 상태 배지 ("3/6 확인 질문" 등) + 마감일 D-n 표시
- [ ] 기존 7개 라우트 전부 301 리다이렉트 동작 (IA.md 표 기준)

## /app (프로젝트 목록)
- [ ] 카드: 프로젝트명(공고명 자동), 상태, 마감 D-n, 이어하기 버튼 → 현재 단계로 딥링크
- [ ] 빈 상태 = 붙여넣기 입력 즉시 노출
- [ ] 삭제만 확인 모달, 나머지 액션은 undo 토스트

## /app/p/:id (파이프라인 공통)
- [ ] 상단 스테퍼 1~6: 완료=체크, 현재=강조, 미도달=비활성. 완료 단계는 클릭 이동 가능
- [ ] 모든 입력 자동 저장 (저장 버튼 부재) + "저장됨" 상태 표시
- [ ] 새로고침/재로그인 후 같은 단계·같은 스크롤 위치로 복원
- [ ] 단계 URL 직접 접근 시: 미도달 단계면 현재 단계로 리다이렉트

## 5-draft (작성 캔버스)
- [ ] 2패널: 좌 근거(요구사항·평가기준·내 답변) 고정, 우 슬롯 캔버스
- [ ] AI 초안에 근거 칩 (평가기준/답변 참조 표시), 클릭 시 좌패널 해당 위치 하이라이트
- [ ] 글자수 제한 실시간 카운터, 초과 시 적색 + 6단계에서 검출됨을 사전 표시
- [ ] "나중에 채우기" 항목에 미입력 배지

## 6-export (무결성)
- [ ] 진입 시 자동 검사, C1~C5 항목별 결과 + 실패 항목 → 5단계 슬롯 점프 링크
- [ ] 전체 통과 시에만 기본 다운로드 활성 (우회 경로는 _검증전 파일명)
- [ ] 검사 결과를 프로젝트에 기록 (재진입 시 재검사 없이 표시, 변경 시 무효화)

## 접근성·품질 공통
- [ ] 키보드만으로 6단계 완주 가능, 포커스 링 가시
- [ ] 모바일(390px)에서 파이프라인 열람 가능 (작성은 데스크톱 우선이되 깨지지 않기)
- [ ] 스크린샷 점검: OS 워터마크 등 데모 환경 노출 요소 제거 후 캡처
