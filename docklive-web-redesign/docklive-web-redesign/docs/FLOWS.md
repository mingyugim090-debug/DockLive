# FLOWS — 파이프라인 상태 머신과 화면 규칙

## 프로젝트 상태 머신

상태: `draft(1) → analyzed(2) → questions(3) → form_mapped(4) → drafting(5) → verified(6) → exported`

전이 규칙:
- 앞으로: 각 단계의 완료 조건 충족 시 다음 단계 활성화 (스테퍼에서 클릭 가능해짐)
- 건너뛰기: /app/new에서 "양식만 채우기" 선택 시 1~3 스킵, 상태 form_mapped로 시작.
  이 경우 5단계 좌패널은 공고 근거 대신 "공고 연결하기" 빈 상태를 보여준다.
- 뒤로: 언제든 이전 단계 재방문 가능. 재방문해도 이후 단계 데이터는 보존.
  단, 1단계에서 공고를 교체하면 2~3단계 결과가 무효화됨을 모달로 고지 후 재분석.
- 모든 상태 변화는 자동 저장. "저장" 버튼은 존재하지 않는다.

## 단계별 화면 규칙

### 1 공고 입력
- 단일 입력 영역: 붙여넣기 / 파일(PDF·HWPX) / URL. 탭이 아니라 하나의 드롭존+텍스트영역.
- 완료 조건: 공고 원문 확보. → 자동으로 2단계 분석 시작 (버튼 클릭 불필요).

### 2 요구사항 분석
- 출력: 마감일·자격·제출서류·평가기준 카드. 각 카드에 원문 근거 하이라이트 링크.
- 평가기준 카드에는 배점 표기 (5단계에서 힘 배분의 근거가 됨).
- 완료 조건: 사용자가 "분석 확인" (수정 가능 상태로).

### 3 확인 질문
- 공고에 없는 정보만 질문. 질문마다 "왜 묻는지" 근거 1줄.
- 전부 필수 아님: "나중에 채우기" 허용 → 5단계에서 해당 항목에 미입력 배지.

### 4 양식·슬롯 매핑
- 좌: 양식 미리보기(구조 트리), 우: 감지된 슬롯 목록 (표 셀/문단/누름틀).
- 자동 감지 실패 슬롯은 사용자가 미리보기에서 클릭해 직접 지정.
- 템플릿 탭: 기존 Templates 콘텐츠. 선택 시 동일 플로우.
- 완료 조건: 슬롯 1개 이상 매핑.

### 5 항목별 작성 (2패널 캔버스)
- 좌(고정): 요구사항·평가기준·내 답변 — 읽기 전용 근거 패널.
- 우: 슬롯 목록 순회. 슬롯마다 [AI 초안] [직접 입력] 두 동작.
  AI 초안에는 어떤 근거(평가기준 n번, 내 답변 m번)를 썼는지 칩으로 표시.
- 글자수 제한 슬롯은 실시간 카운터 (초과 시 적색).
- 완료 조건 없음 — 언제든 6단계로 이동 가능 (미채움은 6단계가 잡는다).

### 6 무결성 검사 + export
- 진입 시 자동으로 무결성 검사 실행: C1~C5 항목별 ✅/❌ + 미채움 슬롯 목록.
- ❌ 항목 클릭 → 해당 슬롯의 5단계 위치로 점프.
- 전부 ✅일 때만 "HWPX 다운로드" 활성화. (강제 다운로드가 필요하면 "검사 무시하고
  다운로드"를 보조 링크로 — 단 파일명에 _검증전 접미사)
- export 후: 산출물 탭에 버전 기록 (다운로드 이력).

## 빈 상태 / 에러 규칙
- 빈 프로젝트 목록: "첫 공고를 붙여넣어 보세요" + 붙여넣기 입력 즉시 노출 (버튼 한 번 아끼기).
- 분석 실패: 무엇이 안 됐고(스캔 PDF 등) 무엇을 하면 되는지(텍스트 붙여넣기) 제시.
- 업로드 실패: 지원 형식과 용량 한도를 에러 안에서 즉시 안내.
